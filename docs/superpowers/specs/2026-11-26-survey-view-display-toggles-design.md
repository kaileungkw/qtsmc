# 中三選科表覆核：原圖、增強對比及雙填選單

日期：2026-11-26  
狀態：設計及書面規格已獲確認；本機實作與真實掃描驗收完成，待發佈 v2.14.1

## 目標

在現有三頁連續覆核檢視器加入與 MC 答題紙一致的兩個獨立顯示控制：

1. **原圖／顯示標記**：隱藏或恢復所有覆核標記。
2. **增強中／增強對比**：開關 MC 現有的 levels／gamma 筆跡增強，預設開啟。

兩者只影響畫面，不改變辨識、手動修正、覆核狀態或匯出。同時修正「請選定」雙填選單過大及過窄的顯示問題。

## 方案

重用 MC `SheetCanvas` 的 LUT，不複製另一套數值，也不使用效果較弱的 CSS contrast。把 LUT 及 canvas 套用函數抽成共用模組，供 MC 和 `SurveyReviewPageCanvas` 使用。

## 介面及狀態

- 在 `SurveyReviewModal` 工具列加入 MC 同款的 Eye／EyeOff 及 Contrast 圖示、文字和 `view-toggle` 樣式。
- `cleanView` 預設 false；顯示標記時按鈕為「原圖」，隱藏後為「顯示標記」。
- `enhanceView` 預設 true；開啟時顯示「增強中」，關閉時顯示「增強對比」。
- 兩個狀態互不改變：原圖模式仍可獨立開關增強，與 MC 行為一致。
- 三頁共用相同狀態；捲動、頁碼定位、問題定位及切換學生不會重設。
- 工具列與頁碼、縮放控制共用可換行 flex；390px 下不可產生文件橫向溢出。
- 不增加持久化偏好或額外說明文字。

## 雙填選單尺寸

現有 `.survey-review-item select` 固定為 68px，且沒有統一 `font-size`，令「請選定」及箭頭顯得過大、過窄。

- 所有排序選單明確使用 13px 字體。
- 一般數值選單維持 68px。
- 含「請選定」的雙填選單加寬至 84px，保留現有高度、紫色邊框及完整點擊範圍。
- 右欄文字可換行並保留 `min-width: 0`，不能因選單加寬而令桌面或手機頁面爆寬。
- 修正後「請選定」不得被箭頭遮蓋、截斷或換行。

## Canvas 資料流程

`SurveyReviewPageCanvas` 繼續保留未修改的渲染來源 canvas。每次顯示時：

1. 把來源複製到顯示 canvas。
2. 若 `enhanceView` 為 true，以共用 LUT 處理顯示 canvas 的 RGB 像素。
3. 若 `cleanView` 為 false，才畫網格外框、考生號碼文字、正常／淡色圓圈及雙填紫框。
4. 若 `cleanView` 為 true，完全不畫任何標記。

因此增強不會改變標記顏色，切換控制亦不會重新讀取 PDF。MC `SheetCanvas` 改用同一函數，但處理次序、LUT 數值及輸出必須不變。

## 錯誤及邊界

- 頁面載入失敗時沿用現有錯誤及重試，顯示控制不影響重試。
- 未能辨識頁面的錯誤提示仍可顯示；不把它當成覆核標記隱藏。
- 修改答案只重畫目前顯示狀態，不重設原圖或增強選擇。
- 原始掃描 Blob、保存工作及匯出檔不會被像素處理改寫。

## 驗收

以真實掃描在本機及正式環境測試：

- 原圖模式移除網格、文字、正常圓圈及紫框；恢復後同一批標記回到原位置。
- 關閉增強與開啟增強的掃描像素有實際差異；紙白保持 255，標記顏色不受 LUT 影響。
- 原圖與增強可任意組合，三頁均套用同一模式，切換學生後保持。
- 切換控制不重新載入 PDF，不造成頁碼或捲動位置異常。
- 390、768、1440 寬度無橫向溢出，按鈕全框可點擊，console error 為 0。
- 雙填選單實測為 84px／13px，一般選單為 68px／13px；「請選定」完整顯示，選單不會遮蓋科目名稱。
- MC 覆核頁使用相同測試確認增強及原圖輸出無回歸。
- `npm run build` 通過後發佈 v2.14.1。
