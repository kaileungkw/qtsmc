# QTSMC 答題紙批改

一個為老師而設的 MCQ 答題紙批改系統。上載掃描或 PDF 後，系統會在**瀏覽器內**找出三個答題框、讀取每格填畫、計算學生成績，並產生每題答對率及每個選項的百分比。所有影像及成績只留在使用者的瀏覽器（IndexedDB），不會上傳到伺服器。

> 第一張答題紙預設為**答案卷（滿分）**；可隨時改以另一張作答案卷。

## 功能

- **多種輸入**：JPG / PNG / WEBP 及多頁 PDF（PDF 自動逐頁拆開）。
- **自動辨識**：定位答題框、校正輕微歪斜、自動處理 90° / 180° / 270° 旋轉。
- **自動光暗校正**：掃描會先做 Levels + Gamma 正規化，把紙底拉白、淡色鉛筆痕加深；對手機相片、影印件及光暗不均的掃描更穩定。
- **覆核可切換增強對比**：標記圖右上角可即在「增強中」與原圖之間切換，方便用肉眼確認極淡的填畫；此開關不影響已計算的分數。
- **答案卷與自動題數**：以第一張為標準；按答案卷及全班作答情況自動判斷本次題數（例如 24 題），未使用的 Q25–60 不會計入滿分。
- **答案卷預設不計入統計**：第一張只作答案標準，不會拉高全班平均或題目百分比；如想計入，可在匯出頁開啟。
- **自動班別／學號**：讀取左上角 Level / Class / Class No 的填畫，組合成班別（如 `4A`）及四位數學號（如 `4103`）。系統會提示未能讀取或重複的學號，方便手動覆核。
- **逐題覆核**：彩色標記圖顯示系統判定的答案；低信心、多選（multi）及 `blank` 會另外標示。
- **blank 納入覆核**：成績表有「有 blank」篩選及「有 blank」狀態；按「需覆核」進入覆核畫面時，blank 題目亦會列出，方便檢查是否漏填或太淡。blank 仍然是 0 分，不會自動當作答對。
- **答案卷編輯器**：可直接修改任何一題的標準答案，成績即時重新計算。
- **姓名/班別/學號**：可直接在成績表修改；「批次命名」可貼上 `4103 陳文麗` 形式的學號＋姓名，系統會按學號配對。
- **完整統計**：平均分、中位數、最高/最低、標準差、及格率、分數分佈、每題答對率、每個選項（A/B/C/D/blank/multi）的人數及百分比。
- **blank 顯示**：所有空白作答一律顯示 `blank`（介面、Excel、CSV 一致）。
- **18 題或 24 題皆可**：系統按答案卷及全班作答自動判斷題數；也可以在答案卷編輯器手動設定。
- **匯出**：
  - Excel `.xlsx`：成績總表、題目分析、選項統計（長表，方便樞紐分析）、答案卷、統計摘要、設定。
  - CSV `.zip`：四個 UTF-8（含 BOM）CSV。
  - JSON 備份：包含答案、設定、分數及自訂答案，不包含原始影像。
- **手機 / iPad 版面**：成績表有 sticky 欄位及姓名旁查看按鈕；題目分析在手機／iPad 會轉為卡片；覆核畫面在 iPad 為左右分欄、手機為上下分欄，並提供放大／縮小及橫向滑動提示。
- **本機自動儲存**：重新整理瀏覽器不會失去已批改的內容；可手動「新工作」清除。
- **隱私**：沒有後端、沒有 API key、沒有分析追蹤；影像不會離開裝置。

## 使用流程

1. 上載整疊答題紙（或一個多頁 PDF）。第一張會自動設為答案卷。
2. 按「開始自動批改」。系統會逐張辨識並顯示進度。
3. 到「成績總表」檢查學生姓名；按任何一行開啟標記圖覆核。
4. 到「題目分析」查看每題答對率與選項百分比；到「選項分佈」看視覺化分佈。
5. 在「匯出」填上測驗名稱、科目、班別、日期及及格分數，下載 Excel / CSV。

### 答案卷與題數

- 答案卷的第一題至最後一題有答案的範圍，就是本次測驗的題數（例如 18 題或 24 題）。
- 系統亦會參考全班作答：只有極少數頁面出現的「背後透印」或雜點，不會把題數拉長。
- 如自動判斷不準，可在「答案卷編輯器」直接修改「本次題數」（1–60），或補上/修改答案。若試卷只有 18 題，鍵入 18 後 Q19–60 便不會計分。
- 答案卷本身永遠以滿分顯示；答案卷預設**不計入**全班統計，可在匯出設定中開啟。

### 低信心與 multi

- `low`：填畫較淡或分數接近，系統仍然給出答案，但會在覆核畫面標示，建議老師看一眼原稿。
- `multi`：同一題有兩個明顯填畫，系統不會猜其中一個，會顯示 `multi` 並以 0 分計。
- `blank`：沒有偵測到填畫，以 0 分計。
- 所有修正會即時影響成績、題目分析及匯出。

## 本機開發

需求：Node.js 20+。

```bash
npm install
npm run dev
```

開啟終端顯示的本地網址（預設 `http://127.0.0.1:5173`）。

```bash
npm run build
npm run preview
```

## 部署

本專案是純靜態 Vite 應用，已包含 `vercel.json`，可直接部署到 Vercel：

```bash
vercel --prod
```

- GitHub repo：<https://github.com/kaileungkw/qtsmc>
- Vercel production：<https://qtsmc.vercel.app>

GitHub Actions 會自動執行 `npm ci && npm run build` 作建置檢查（見 `.github/workflows/ci.yml`）。

如要每次 push 到 `main` 都自動部署，Vercel 的 GitHub App 需要授權此 repo（Vercel 帳戶目前只開放了部分 repo）。到 <https://github.com/settings/installations/96342233> 把 `qtsmc` 加入 Repository access，然後執行：

```bash
vercel git connect https://github.com/kaileungkw/qtsmc.git
```

目前 production 版本已由 Vercel CLI 部署；自動部署授權後即可改為 Git push 觸發。

## 技術原理

- 影像在 Web Worker 內以 1500px 工作寬度處理。
- 以積分影像做 adaptive threshold，找出所有深色像素。
- 掃描頁面上連續的長垂直線，配對成三個答題框；再以固定版面比例（在 21 頁真實掃描上量度）定位 20 × 4 格。
- 每格先以印刷氣泡邊框做 ±3px 對位，再量度中央区域的填畫深度；另以中央亮度中位數偵測很淡的鉛筆痕。
- 以答案卷及全班共識判斷實際題數，避免把背面透印當成答案。
- 匯出使用 ExcelJS（瀏覽器端產生 xlsx）及 JSZip（CSV 壓縮）；PDF 拆頁使用 PDF.js。

## 測試與已知限制

- 已用 21 頁真實 A4 掃描（PDF）測試：21/21 頁成功定位三個答題框，正確判斷 24 題，沒有 console error；Excel 與 CSV 內容、顏色、blank 顯示均已驗證。
- 自動對比增強測試：可讀回原本因太淡而漏讀的 Q3（page 15）及多頁的班別/學號；Q4（page 15）及 page 14 Q7 的痕跡接近紙張雜訊，仍會顯示 `blank`，需人手覆核。
- 已測試手機直拍、90° / 180° 旋轉、單張與 21 頁 PDF、重新載入後恢復、答案卷修改、JSON 備份匯入。
- 手寫姓名／科目**不會自動 OCR**；請用批次命名或直接在成績表輸入。
- 班別／學號會嘗試讀取左上角填畫；如果學生把學號寫在格子上方而沒有填泡泡，或填得極淡，系統可能讀不到，會顯示提示讓你手動更正。
- 非常淡或已被擦除的鉛筆痕可能需要人手覆核；自動增強會盡量加深，但仍可能在該格顯示 `blank`，可用覆核畫面的「增強對比」核對原稿。
- 相片應包含完整答題紙；嚴重透視變形、手指遮蓋或裁切可能影響辨識。
- 建議使用最新版 Chrome、Edge 或 Safari（需要 Web Worker + OffscreenCanvas）。不支援的瀏覽器會顯示提示。

## 專案結構

```
src/
  App.tsx                 工作流程與狀態
  components/             上載、成績表、題目分析、覆核、答案卷編輯器等
  lib/
    marker.ts             影像前處理、答題框定位、取樣與答案判定
    marker.worker.ts      Web Worker 入口
    scoring.ts            計分、統計、自動題數
    export.ts             XLSX / CSV / JSON 匯出
    pdf.ts                PDF 逐頁轉圖
    storage.ts            IndexedDB 自動儲存
```

## Vercel 用量與收費

- 這是**純靜態網站**，沒有 Serverless Function、沒有後端資料庫。Vercel 只負責送出 HTML/CSS/JS 檔案。
- 老師上載的掃描影像**不會經 Vercel**；辨識、計分及 Excel/CSV 產生全部在瀏覽器內完成，所以不會消耗 Vercel 的 Function 執行時間。
- 第一次開啟約下載 1–2 MB 程式（之後由瀏覽器快取）；ExcelJS、PDF.js 等會按需要才載入。以校內幾十位老師、每班幾十份卷的使用量，Vercel 免費 Hobby 計劃的每月 bandwidth 一般足夠。
- 如學校大量使用或需要自訂網域／密碼保護，可再考慮 Vercel Pro 或把 `dist/` 放到校內伺服器；程式本身不需要 Vercel 才能運作。

## 私隱

本工具沒有後端。所有掃描影像只會存在瀏覽器記憶體及本機 IndexedDB；關閉或清除瀏覽器資料後便會移除。部署到 Vercel 只是提供靜態程式檔案，不會接收或儲存任何學生資料。
